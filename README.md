# CartIQ

Smart modular trolley attachment system for queue-less retail shopping.

## Problem Statement
Large supermarkets often have long billing queues that waste customer time and create crowding during peak hours.

## Solution
CartIQ transforms existing supermarket trolleys into smart self-checkout assistants using a modular attachment system.

Customers can:
- scan products while shopping
- view live billing
- navigate store sections
- pay directly on the trolley
- exit without standing in billing queues

## Core Features
- Smart trolley display
- Barcode scanning system
- Live cart and billing
- Section-based navigation
- Seamless payment integration
- Queue-less checkout experience

## Navigation System
The trolley provides section-based navigation such as:
- Snacks Section
- Refrigerated Section
- Oil Section
- Bakery Section
- Household Section

This keeps the system practical and easy to maintain for real supermarkets.

## Hardware Concept
The system is designed as a modular attachment for existing supermarket trolleys using:
- touchscreen display
- barcode scanner
- Raspberry Pi
- rechargeable battery
- WiFi connectivity

## Tech Stack
